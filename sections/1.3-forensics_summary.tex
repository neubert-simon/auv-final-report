\subsection{Digital Forensics}

The Spearphishing attack the user suffered was conducted via a Phishing E-Mail.
The attackers impersonated Microsoft support, claiming urgent action was required.
That goaded the user into clicking a malicious link, which copied a PowerSell command into their clipboard and instructed them to execute it.
The command then downloaded a script which encrypted some files and created a ransom note.

\textit{Educating and training users to spot Phishing attempts can help them avoid being victimized. Additionally, web content can be restricted to reduce the risk of malicious content being accessed.}
